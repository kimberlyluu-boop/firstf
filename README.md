# firstf
My first repo on github!

## how the command works
The command finds a specified pattern in the first N lines. Firstf combines the grep and head commands to find a pattern in a group of lines. This can be used in a large file with too many lines to use only head or grep and can be ran through Codio or any system that uses Node.js
