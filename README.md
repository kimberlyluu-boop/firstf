## how the command works
The command finds a specified pattern in the first N lines. 
## AI assisted programming reflection
This project helped my further understand how Linux commands work and how command-line arguments such as grep, head, or cat work in a Node.js. By creating firstf, I learned how to combine both these commands by implementing them through javascript.

I implemented AI through this code by using it to test my code and flag any errors that may come up during real situations where this code can be used. This led to the 'Empty pattern', 'invalid number', and 'check number of lines'. 

One of the most important things I learned through this workshop was process.argv. I learned how it it is used to retrieve information from the command line. I also learned how to check whether a file exists and split contents into separate lines.
